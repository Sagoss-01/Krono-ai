# ⌨️ Raccourcis clavier — TechSphere Webmail

> Accès rapide : appuyez sur **`?`** dans l'application pour ouvrir la page d'aide dans un nouvel onglet.

---

## 📧 Messagerie

| Touche | Action |
|--------|--------|
| `R` | Répondre à l'email ouvert |
| `F` | Transférer l'email ouvert |
| `D` | Supprimer l'email ouvert *(confirmation requise)* |
| `U` | Marquer lu / non-lu |
| `S` | Étoiler / retirer l'étoile |
| `/` | Focus sur la barre de recherche |
| `Esc` | Fermer la vue email (mobile) |

---

## 💬 Discussions (Chat)

| Touche | Action |
|--------|--------|
| `Enter` | Envoyer le message |
| `Shift + Enter` | Nouvelle ligne dans le message |

---

## 🧭 Navigation générale

| Touche | Action |
|--------|--------|
| `?` | Ouvrir la page d'aide dans un nouvel onglet |
| `Esc` | Fermer les modales et panneaux |

---

## 🗂️ Filtres rapides (sidebar)

Cliquer sur la flèche **`>`** à droite de **Boîte de réception** dans la sidebar pour déplie les sous-sections :

- **Non lus** — affiche uniquement les emails non lus
- **Étoilés** — affiche uniquement les favoris
- **Pièces jointes** — affiche uniquement les emails avec PJ

---

> ⚠️ Les raccourcis clavier ne fonctionnent pas quand le curseur est dans un champ texte.
